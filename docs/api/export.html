Fields

Field Type Required Description

load

GET /export

Operation ID: raw-event-export.

Authentication: basic token (ProjectSecret).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | project_id | query | integer | No | Required if using service account to authenticate request. | | from_date | query | string | Yes | The date in yyyy-mm-dd format to begin querying from. This date is inclusive and interpreted as UTC timezone for projects created after 1 January 2023 and current project timezone for projects created before 11 January 2023. | | to_date | query | string | Yes | The date in yyyy-mm-dd format to query to. This date is inclusive and interpreted as UTC timezone for projects created after 1 January 2023 and current project timezone for projects created before 11 January 2023. | | limit | query | integer | No | Use this parameter if you want to limit the max number of events to be returned. Value cannot be over 100000. | | event | query | string | No | The event or events that you wish to get data for, encoded as a JSON array (for example, [&quot;signup&quot;,&quot;purchase&quot;]). | | where | query | string | No | An expression to filter events by. More info on expression sequence structure can be found here | | time_in_ms | query | boolean | No | Defaults to false which will export event timestamps with second-precision. Set to true to export event timestamps with millisecond-precision. | | Accept-Encoding | header | enum: gzip | No | If set to gzip and the response body is > 1400 bytes, the response will be compressed with gzip, and Content-Encoding will be set to gzip. |
